# Simon Game 🎮

A browser-based implementation of the classic **Simon Says** memory game built with **Vanilla JavaScript**.

## 🚀 Live Demo
> Coming soon — deploying on Netlify

## 🛠️ Tech Stack
- HTML5
- CSS3 (animations & flash effects)
- Vanilla JavaScript (DOM manipulation, game state management)

## 🎯 Features
- Progressive level difficulty — sequence grows each round
- Color flash animations for both game and user input
- High score tracking across sessions
- Keyboard + click input support
- Game over detection with instant feedback

## 🧠 How It Works
1. Press any key to start the game
2. Watch the color sequence the game plays
3. Repeat the sequence by clicking the colored buttons
4. Each correct round adds one more step to the sequence
5. Wrong input ends the game and shows your score

## 📁 Project Structure
```

└── app.js        # Game logic, sequence tracking, high score
```
